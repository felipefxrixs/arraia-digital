# Arraia Digital

Projeto web estatico para o fluxo de visitantes do Arraia Digital.

## Estrutura

```text
.
├── assets/
│   └── arraia-digital-fundo.png
├── fluxo_visitante_arraia_digital.html
├── Dockerfile
├── docker-compose.yml
├── nginx.conf
└── README.md
```

## Executar com Docker

```bash
docker compose up --build
```

Depois acesse:

```text
http://localhost:8080
```

## Executar sem Docker

Abra o arquivo `fluxo_visitante_arraia_digital.html` em um navegador.

## Conteudo enviado

O repositorio contem apenas os arquivos necessarios para executar o projeto.
Arquivos de apoio, backups e documentos da disciplina foram deixados fora do Git.
